# 🇮🇹 BandoAlert Italia

MicroSaaS per trovare bonus, incentivi e opportunità in Italia.

## Obiettivo
Creare un assistente digitale che aiuta gli utenti a:

- trovare opportunità compatibili con il proprio profilo;
- capire documenti e requisiti con IA;
- ricevere alert sulle scadenze.

## MVP

- Landing page
- Ricerca bandi
- Profilo utente
- Opportunità salvate
- Piano Free/Premium
- Assistente IA

## Stack previsto

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Stripe

## Roadmap

1. Prima versione pubblica
2. Database utenti
3. Alert automatici
4. Abbonamento Premium
