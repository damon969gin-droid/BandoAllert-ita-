# BandoAlert Italia - Free Stack

Obiettivo: mantenere il progetto con costi iniziali pari a 0 euro.

## Architettura gratuita

Frontend:
- Cloudflare Pages (hosting gratuito)
- Next.js

Backend:
- Cloudflare Workers per API leggere

Database:
- Cloudflare D1 SQLite per partire senza costi

Storage:
- Cloudflare R2 quando necessario

Autenticazione:
- inizialmente sistema semplice con Workers + D1
- valutazione servizi esterni solo dopo crescita utenti

## Regola progetto

Nessun servizio a pagamento fino a quando il prodotto non genera entrate.

Prima monetizzazione:
- Premium mensile
- servizi IA avanzati
- alert personalizzati
